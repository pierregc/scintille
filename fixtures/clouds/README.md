# Cloud fixture

`gmgsi_20260715T180000Z.webp`: cloud opacity (2048 × 1024 equirectangular grayscale WebP, quality 70; 0 = clear, 255 = opaque), converted from NOAA NESDIS GMGSI longwave IR for 2026-07-15 18:00 UTC, the instant of the lightning fixtures ([ADR 0007](../../docs/adr/0007-cloud-source.md)). NOAA open data, contains EUMETSAT Meteosat and JMA Himawari data.
