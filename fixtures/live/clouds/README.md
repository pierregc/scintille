# Cloud fixture

A cloud manifest ([format](../../../docs/data-contract.md#cloud-frames-on-r2)) with one frame,
`2k/20260715T180000Z-f7492cd2.webp`: cloud opacity (2048 × 1024 equirectangular grayscale WebP, quality 70; 0 = clear, 255 = opaque), converted from NOAA NESDIS GMGSI longwave IR for 2026-07-15 18:00 UTC, the instant of the lightning fixtures ([ADR 0007](../../../docs/adr/0007-cloud-source.md)). The `4k` tier points to the same 2k file to keep the fixture small. NOAA open data, contains EUMETSAT Meteosat and JMA Himawari data.
