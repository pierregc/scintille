# Assets

Globe textures are generated by `web/scripts/textures/build.mjs`, uploaded to R2, and never committed.

## Regenerate

```sh
brew install basis_universal   # KTX2 encoder (or set BASISU=/path/to/basisu)
pnpm -C web install
pnpm -C web textures
```

Sources are downloaded once to `web/scripts/textures/.cache/` and verified against a pinned size and
SHA-256. Outputs go to `web/scripts/textures/out/<tier>/` with a `manifest.json` listing every file size.
Both folders are git-ignored.

## Loading in the globe

The Earth shader loads `<PUBLIC_TEXTURES_URL>/4k/{day,night,mask}.webp`. `PUBLIC_TEXTURES_URL` defaults to
`/textures` in dev and to `https://data.scintille.app/textures/v1` in production builds. For local
development, link the generated folder into `public/` (ignored by Git):

```sh
ln -s ../scripts/textures/out web/public/textures
```

For production, upload them to R2 with `pnpm -C web r2:upload textures` ([deploy](deploy.md#textures)).

## Formats

Every tier has three equirectangular textures, each as KTX2 (Basis Universal ETC1S with a full mipmap
chain) and as a WebP fallback.

- `day.*`: sRGB color.
- `night.*`: sRGB city lights.
- `mask.*`: linear grayscale, water = white, land = black. Used for ocean specular.

KTX2 files are stored bottom-up (`-y_flip`) because Three.js cannot flip compressed textures: load them
with `flipY = false`. WebP files are top-down and use the default `flipY = true`. Both map onto
`SphereGeometry` UVs the same way.

## Tier sizes

Measured download size of each tier (day + night + mask), in MB (10^6 bytes):

| Tier | Size | KTX2 day / night / mask | KTX2 total | WebP total |
|---|---|---|---|---|
| `8k` | 8192 × 4096 | 4.30 / 1.43 / 0.42 | 6.16 | 4.09 |
| `4k` | 4096 × 2048 | 1.22 / 0.42 / 0.18 | 1.83 | 1.26 |
| `2k` (mobile) | 2048 × 1024 | 0.36 / 0.14 / 0.08 | 0.59 | 0.40 |

The mobile tier is well under the 4 MB target. Sizes change if encoder settings change: re-run the
script and update this table from `out/manifest.json`.
